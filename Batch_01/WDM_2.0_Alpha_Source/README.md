# WDM 2 alpha

WDM 2 is an independent desktop download manager fork based on Brisk. It is **source-stage alpha**, not an installable Windows release or a claim of feature parity with Internet Download Manager. See [WDM-FORK-NOTICE.md](WDM-FORK-NOTICE.md) and [LICENSE](LICENSE) for GPL-3.0 terms and upstream attribution.

This increment changes the desktop identity, default window size (940 × 600), Windows icon and installer name, and adds a visible light/dark button whose choice persists in settings; download row selection boxes now appear when Select is clicked. It bundles the independently authored WDM Chrome/Edge/Brave extension for media detection and download handoff on local port 3021. The Windows installer source includes an optional per-user startup task. Existing Brisk download engine features such as segmented downloads, categories, queues, and HLS handling remain in the fork. Upstream automatic update checking has been disabled; no WDM update service is configured.

**Current limits:** The Windows binary has not been built or tested here. Extension UI and server interoperability must be confirmed together on a Windows machine. The optional startup task, theme persistence, and HLS download must be exercised in the packaged application. ZIP contents before download, global bandwidth throttling, reliable schedule enforcement, clipboard monitoring, completion sounds, site crawling, and Defender integration have not been completed or validated in this alpha. Blob URLs require a detected underlying media request. Browser DRM streams are outside its scope.

For Windows builds, see [BUILD-WINDOWS.md](BUILD-WINDOWS.md). Run `node test-extension.cjs` for deterministic mock tests of the browser handoff. Unpack and install `extension/` through your Chromium browser's Extensions page after installing the desktop app. The extension is not a store-published extension. The legacy WDM 1.4 installer is a separate product build and cannot serve as the WDM 2 desktop counterpart.
